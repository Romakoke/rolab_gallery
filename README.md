# ROLAB фото + видео галереясы

## Құрамында
- 40 бастапқы фото, 8 видео, ROLAB логотипі
- Адаптивті HTML/CSS/JS (Vite арқылы жинақталады)
- Фото/видео сүзгілері, іздеу, үлкен экранда көру, сақтау сілтемесі
- Кез келген келушінің файл жүктеуі: Vercel Blob + екі API route

## Vercel орналастыру
1. ZIP архивті компьютерге шығарыңыз.
2. GitHub-қа осы қалтаның барлық файлдарын жүктеңіз. `media` қалтасын да қоса жүктеңіз.
3. Vercel → Add New → Project → GitHub репозиторийін таңдаңыз → Deploy.
4. Framework Preset: `Vite` (немесе Other), Build command: `npm run build`, Output directory: `dist`.
5. Vercel жобасы → Storage → Create Database → Blob → **Public** store → Connect to Project.
6. `BLOB_READ_WRITE_TOKEN` айнымалысы production environment-ке қосылғанын тексеріңіз; қажет болса Redeploy жасаңыз.
7. Дайын. Келушілер фото/видео қоса алады, файлдар ортақ галереяға сақталады.

## Шектеулер және қауіпсіздік
- 100 MB / файл; браузерден Blob қоймасына тікелей жүктеледі.
- Қазіргі нұсқада **кез келген келуші тіркеусіз файл жүктей алады**. Бұл спам, орынсыз материалдар және сақтау ақысының көбеюіне әкелуі мүмкін. Жария сайт үшін міндетті түрде CAPTCHA, жүктеу лимиттері, авторизация немесе модерация қосу ұсынылады.
- Бастапқы 48 файл сайтпен бірге жинақталған, жаңа файлдар Blob-та сақталады. Жаңадан жүктелген файлдарды өшіруге арналған әкімші панелі әзірге жоқ.
- Vercel Blob тарифінің көлем/трафик лимиттерін Vercel Dashboard-тан бақылаңыз.
- Суретте адамдар болса, олардың жариялауға келісімін алыңыз.
